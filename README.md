# Graduation Balloons

Balloons Lane website — built with Astro 5 (static site).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static site is output to `dist/` — deploy it on Cloudflare Pages, Netlify or Vercel.
Set the build command to `npm run build` and the output directory to `dist`.

## Contact form

The quote form posts to Formspree — replace `YOUR_FORM_ID` in `src/pages/contact.astro`
(and the home page form) with your real Formspree form ID.
